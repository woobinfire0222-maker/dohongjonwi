이번 수정본

1. 기존 행운의 돌림판 복원
   - mini_game.sql의 play_wheel_game은 기존 30% 당첨 / 70% 실패 로직으로 복원.
   - 화면에서도 '행운의 돌림판'으로 표시.

2. 초보자 룰렛 신규 추가
   - 화면 표기: 50:50
   - DB 규칙: 같은 유저의 beginner_roulette 실행 횟수를 DB에 영속 저장.
   - 1~3회: 무조건 성공, 배팅 2배 지급.
   - 4회 이상: 무조건 실패, 지급 0.
   - RPC: play_beginner_roulette_game(bigint)

3. 다트 신규 추가
   - 타이밍 액션 UI + 다트가 천천히 이동하는 연출.
   - 서버 판정: 적중 60%, 실패 40%.
   - 적중/실패 결과에 강한 시각 효과 적용.
   - RPC: play_dart_game(bigint)

4. 모바일 채팅 계급 표시 보강
   - 계급 배지를 별도 chat-rank-badge로 표시해 모바일에서도 이름/시간에 밀리지 않도록 수정.

5. 프로필 저장 후 계약서로 돌아가는 버그 수정
   - 저장된 프로필을 부모 상태로 반영할 때 contract_accepted / contract_version을 유지하도록 수정.

6. 모바일 왼쪽 탭 목록 스크롤
   - 사이드바 메뉴에 세로 스크롤을 허용해 작은 화면에서 항목이 잘리지 않도록 수정.

Supabase 적용
- mini_game.sql: 기존 게임 함수 복원/기본 게임 SQL
- beginner_roulette_dart.sql: 신규 초보자 룰렛 + 다트 및 actionCount 테이블/RPC
